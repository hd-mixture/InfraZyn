# **App Name**: DevTeXhHub

## Core Features:

- Authentication & Authorization: User authentication with role-based access (Admin, Project Manager, Developer).
- Dashboard Overview: Dashboard displaying total revenue, project count, time spent, and active users.
- Project Summary: Interactive project summary table showing project details, status, and progress.
- Task Management: Task management features including create, update, delete, and assign tasks with status tracking.
- File Attachments: Storage of project files using Firebase Storage.
- Delay Prediction: A tool which analyzes task descriptions and deadlines to predict potential delays.

## Style Guidelines:

- Primary color: Light orange (#FFB347), inspired by the Promage dashboard, to bring a sense of energy and focus.
- Background color: Beige (#F5F5DC), mirroring the Promage design for a calm, neutral backdrop.
- Accent color: Dark brown (#8B4513), analogous to the primary, providing contrast and grounding.
- Body and headline font: 'PT Sans', a humanist sans-serif, offers both a modern and inviting aesthetic for headings and body text.
- Use a consistent set of icons for navigation and actions, similar to Promage, to maintain a clean and intuitive interface.
- Mimic the Promage dashboard layout with a sidebar, overview cards, project summary table, and top search bar.
- Subtle animations on task status changes to provide visual feedback and enhance user experience.
