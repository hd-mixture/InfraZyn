# DevTeXhHub - A Comprehensive Project Management Dashboard

DevTeXhHub is a modern, full-featured project management application designed to streamline workflows for software development teams. It provides distinct, role-based dashboards for Admins, Managers, Developers, QAs, and Designers, ensuring that every team member has the tools they need to be productive.

## Features

### Role-Based Dashboards

- **Admin Dashboard**: A system-wide overview of all projects, users, tasks, and revenue. Admins can manage projects, create and manage user accounts for all roles, and view high-level analytics.
- **Manager Dashboard**: Focused on project and team management. Managers can create tasks for their assigned developers, QAs, and designers, track project progress, and manage their team members.
- **Developer Dashboard**: A personalized view for developers to see their assigned tasks, update task status and progress, complete tasks, and view their completed projects.
- **QA Dashboard**: A dedicated space for Quality Assurance engineers to manage testing tasks, create and track bug reports, and manage test cases.
- **Designer Dashboard**: A creative workspace for designers to manage their design tasks, create and view moodboards, and submit their final designs.

### Core Functionalities

- **Project Management**: Create, edit, and delete projects. Track progress, status, priority, and budget.
- **Task Management**: A robust Kanban-style task board to visualize workflows. Create detailed tasks for different roles (Development, QA, Design) with attachments, priorities, and due dates.
- **User Management**: Admins can create managers, developers, QAs, and designers. Managers can create users for their own teams. User profiles can be edited and updated.
- **AI-Powered Delay Prediction**: An innovative feature for Admins to predict the likelihood of task delays using Genkit and Google's Gemini models.
- **Real-time Notifications**: A built-in notification system to keep users updated on new task assignments and comments.
- **Authentication**: Secure login system powered by Firebase Authentication.

## Tech Stack

- **Framework**: Next.js (with App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: ShadCN UI
- **Backend & Database**: Firebase (Firestore, Authentication)
- **Generative AI**: Google's Genkit (with Gemini models)
- **File Storage**: Cloudinary for image and file uploads.
